# release-notes-page

A one-file Python script (standard library only) that turns `git log <last-tag>..HEAD` into a release-notes web page, and publishes it to a public [deed.page](https://deed.page) link only after you type `y`.

Tutorial: see `index.html` (also served as a static site). API docs: https://deed.page/docs. Agent skill with the same ask-before-publish flow: https://github.com/f-o-x11/deed-page-skill
